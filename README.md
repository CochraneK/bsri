# BSRI 性别角色探索测验（贝母量表中文版）

一个**移动优先**的性别角色自我探索网页，基于 Sandra Bem (1974) 的
**性别角色量表（Bem Sex Role Inventory, BSRI）** 编制。60 题 7 点量表，
帮你在「男性化 / 女性化」两个独立维度上看见自己的交织方式，并在
**四象限落点图**上找到自己的位置、看见其他填写者的分布。

线上地址：https://cochranek.github.io/bsri/

## 功能
- 📱 手机友好：单栏响应式、大按钮、进度条
- 🚻 开场只问性别（👦 男生 / 👧 女生），用于落点图配色与对照（男=蓝、女=粉）
- 🧮 原始 BSRI 计分：男性化(M)、女性化(F) 各自 20 题均值，固定分界 5.0
- 🌐 四象限落点图：横轴 M、纵轴 F，5.0 虚线分界；男蓝、女粉
- 👥 可见**其他填写者的落点**：
  - 接入后端时显示**实时真实累积**的全体落点；
  - 纯静态（GitHub Pages）时回退到内置**匿名聚合样本**，保证始终能看见分布
- 📝 暖心 / 启发 / 客观谨慎的四种类型详细解读
- 📸 一键**下载报告截图**（PNG）
- 📥 一键**下载个人作答数据**（JSON，可拿去和其他 AI 深入交流）
- 💡 提醒：下载的数据可直接交给别的 AI，做更深度的对话

## 计分与分类规则
| 维度 | 题数 | 计分 |
|---|---|---|
| 男性化 (M) | 20 | 20 题均值（1–7） |
| 女性化 (F) | 20 | 20 题均值（1–7） |
| 中性（填充，不计分） | 20 | 仅用于降低作答偏性 |

7 点量表：1=很不符合，2=基本不是，3=比较不符合，4=说不清，5=较符合，6=基本符合，7=很符合

分类（固定分界值 5.0，维度均值 ≥5 视为该特质「高分」）：
- **双性化**：M≥5 且 F≥5
- **男性化**：M≥5 且 F<5
- **女性化**：M<5 且 F≥5
- **未分化**：M<5 且 F<5

> 标准原版题目按「每 3 题一组（M→F→中性）」循环混合排列，计分一律按类别汇总，与呈现顺序无关。
> 本测验仅供自我探索与科普，**不构成任何临床诊断**。

## 目录结构
```
index.html                单文件前端（内联 CSS/JS，含题项、计分、报告、绘图）
server.py                 可选后端（跨平台）：累积真实落点，提供 /api/submit、/api/points
assets/data/history.json  内置匿名聚合样本（纯静态部署时的回退数据源）
requirements.txt          server.py 依赖（flask）
.gitignore                运行期 data/ 与 Python 缓存不入库
```

## 本地预览（纯静态，无后端）
```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
此时落点图会使用内置匿名样本，仍可完整体验。

## 本地运行（带真实后端，累积真实落点）
```bash
pip install -r requirements.txt
python server.py                 # 默认 http://0.0.0.0:8000
PORT=9000 python server.py       # 自定义端口
```
后端把每个填写者的 (M, F, 性别, 类型) 落点写入 `data/points.json`
（该目录已被 .gitignore 忽略，不入库），并通过 `/api/points` 返回全体落点。
前端优先用真实后端；若后端不可用（如 GitHub Pages 纯静态），
自动回退到 `assets/data/history.json` 的匿名样本，保证始终可见他人分布。

## 部署
- **GitHub Pages（纯静态）**：直接把 `index.html`、`assets/data/history.json` 推到
  `main` 分支根目录即可，落点图使用内置样本。
- **带后端部署**：在本机 / 云服务器运行 `server.py`，把 `API_BASE` 指向后端域名，
  即可累积并显示真实全体用户的落点。
