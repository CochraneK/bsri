# 性别角色探索测验（贝母 BSRI 中文版）

一个**纯静态、移动优先**的性别角色自我探索网页。基于 Sandra Bem (1974) 的
**性别角色量表（Bem Sex Role Inventory, BSRI）** 编制，60 题 7 点量表，
帮你看见自己“男性化 / 女性化”两种特质的交织方式，并在**四象限落点图**上找到自己的位置。

## 功能
- 📱 手机友好：单栏响应式，大按钮，进度条
- 🚻 开场先问性别（男 / 女 / 不愿透露），用于结果图配色与对照
- 🧮 原始 BSRI 计分：男性化(M)、女性化(F) 均值 + 中位数分割分类
- 🌐 四象限落点图：横轴 M、纵轴 F，虚线为常模参考中位数；男蓝、女粉、不愿透露紫
- 👥 可见**匿名历史被试的聚合落点**（展示分布形态）
- 📝 暖心 / 启发 / 客观谨慎的四种类型详细解读
- 📸 一键**下载报告截图**（PNG）
- 📥 一键**下载个人作答数据**（JSON，可拿去和其他 AI 深入交流）
- 🔒 数据仅存本地，不上传

## 计分与分类规则
| 维度 | 题数 | 计分 |
|---|---|---|
| 男性化 (M) | 20 | 20 题均值（1–7） |
| 女性化 (F) | 20 | 20 题均值（1–7） |
| 中性（填充，不计分） | 20 | 仅用于降偏 |

分类（中位数分割，参考中位数 M≈4.9 / F≈4.9）：
- **双性化**：M≥4.9 且 F≥4.9
- **男性化**：M≥4.9 且 F<4.9
- **女性化**：F≥4.9 且 M<4.9
- **未分化**：M<4.9 且 F<4.9

> 参考中位数来自 Bem 大样本常模估计；不同样本在 4.4–4.9 间浮动。
> 本测验仅供自我探索，**不构成临床诊断**。

## 关于“历史落点”
纯静态 GitHub Pages 无法实时聚合所有用户数据。本仓库内置一份
**匿名聚合样本**（`history.json`，420 个点，按四类比例合成）用于展示分布形态。
如需**真实、实时累积**其他用户的落点，需接入后端（如 Supabase / Cloudflare Workers /
GitHub Issues API），可在此基础上扩展。
